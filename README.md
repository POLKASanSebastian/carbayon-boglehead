# Carbayón Boglehead · Apuntes de estudio

Resúmenes interactivos, capítulo a capítulo, del libro **Carbayón Boglehead. De la inversión pasiva a la libertad financiera**, de David Blanco.

- `index.html` — portada con el libro, el índice de capítulos, buscador y progreso de lectura.
- `capitulos/` — un HTML por capítulo (17 capítulos + reflexiones finales), con navegación anterior / siguiente y botón "Marcar como leído".
- `img/portada.jpg` — foto de la portada.

## Publicarlo con GitHub Pages

1. Crea un repositorio nuevo en GitHub (por ejemplo `carbayon-boglehead`).
2. Sube todo el contenido de esta carpeta tal cual (con `index.html` en la raíz).
3. En el repositorio: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, rama `main`, carpeta `/ (root)`. Guarda.
4. En un par de minutos la web estará en `https://TU-USUARIO.github.io/carbayon-boglehead/`.

El progreso de lectura se guarda en el navegador de cada persona (localStorage), sin servidor.
